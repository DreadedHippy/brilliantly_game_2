# Game assets

`ui/tutorial-finger.png` is the transparent, image-generated pointing-hand cursor for the mentor practice spotlight. It is displayed without stretching and animated with CSS; reduced motion keeps it stationary. The original prompt and route are in `ui/tutorial-finger.provenance.json`.

The masked twin-sickle enemy idle is in `sprites/bell-mask-enemy/`, with a standalone `preview.html` and sibling `bell-mask-enemy-bundle.zip`. Six smooth painted poses play forward/back as ten 200ms steps for a two-second idle, retaining the tall bell-topped mask, indigo robes, raffia, twin blades and faint cyan wisps. Frames are 512×384 with root `[256,320]`; the suggested 96px silhouette height includes the mask and weapons. PNG atlas/strip/frames, animated WebP, Aseprite JSON, engine metadata, original sources, prompts, provenance and exact QA are included. The runtime frame check passes; one small detached effect fragment remains flagged in atlas QA. This is an idle asset, with no encounter placement or battle logic.

Three elemental creature idle sets are available in `sprites/earth-tortoise/`, `sprites/ember-lion/`, and `sprites/wind-owl/`, each with its own `preview.html` and sibling `*-bundle.zip`. They use smooth painted 2D art and transparent elemental effects: breathing/crystal glow for the baobab tortoise, breathing/flame motion for the volcanic lion, and hovering wing flex for the wind owl. Each includes six drawn poses, a two-second pingpong WebP, PNG atlas/strip/frames, animation metadata, source art, prompts, provenance and exact QA reports. Runtime frames are 512×384 with one shared scale per creature; the suggested 80px display height includes the entire silhouette. These are descriptive asset labels, with no assigned lore names or level placement.

The mythical creature's idle set is in `sprites/storm-companion/`. Preview it at `/assets/sprites/storm-companion/preview.html` or download `sprites/storm-companion-bundle.zip`. Six drawn breathing poses play forward and back as ten steps at 5fps for a two-second loop, with restrained mane, tail and electrical motion. Frames are 512×384 with root `[256,320]`; suggested silhouette height is 80px, including horns and the curled tail. PNG atlas/strip/frames, animated WebP, Aseprite JSON, engine metadata, source images, exact prompts, provenance and QA are included. It is one left-facing idle asset; following behavior and level placement are separate work. The current atlas passes structural spill checks, while the first two subtle poses retain a near-duplicate silhouette warning.

Place authored assets here as they become available:

- `sprites/`: character and encounter sprite sheets.
- `maps/`: Tiled JSON maps, tilesets, and region artwork.
- `audio/`: music and sound effects.
- `ui/`: interface artwork and icons.

The home map uses `maps/world-map-v1.webp`, generated with the built-in image-generation tool and encoded as WebP at its original 1672 by 941 dimensions. `maps/world_map_codex.json` owns the asset path, complete prompt, provenance, and region coordinates. The compass, route, markers, and labels are rendered separately so they stay crisp and interactive.

Load assets through a scene's `preload()` using URLs based on `import.meta.env.BASE_URL` so subdirectory hosting works. Vite copies this directory into the production build. Legacy exploration and battle still generate geometric placeholder artwork in `src/game/scenes/art.ts`; no external fonts are needed.

Record creator, source, license, cultural context, and attribution requirements for every imported asset. Do not treat a continent as a single visual culture; establish the game's specific setting before commissioning final artwork.

The main character asset draft lives in `sprites/main-hero/`. Open `/assets/sprites/main-hero/preview.html` through Vite to review idle, walk, and run at source and game sizes. The set includes a transparent master, 20 unique 384×384 poses, PNG atlas, individual frames, per-action strips, animated WebP previews, Aseprite JSON, and Phaser-friendly animation indices in `main-hero.json`. Idle has four breathing poses played in a six-step ping-pong loop; walk and run each have eight poses. Each frame uses the same `[192, 320]` root. Load the atlas as a 384×384 spritesheet and use `animations[action].frames` and `frameRate` from its metadata.

`main-hero/QA.md` records unresolved head-size, phase-coverage, and leg-alternation checks. This is a right-facing art draft for review. `provenance.json`, original prompts, source sheets, and exact QA reports are included. The user selected image-generated frame-by-frame animation; no video provider was used. Stage 1-1 now uses this generated hero; legacy exploration and battle scenes retain their placeholder character. The full asset download is `sprites/main-hero-bundle.zip`; editable processing inputs and scripts are retained under `art/characters/main-hero/`.

The playable Stage 1-1 environment is in `maps/stage-1-1/`. `layout.json` owns the road controls, spawn, NPC, encounter positions, exit and fixed camera configuration; `map-bundle.json` contains the matching walk polygon and six navigation targets. `ground.webp` composes image-generated grass and earth materials along that road. `environment.json` places independently generated props with uniform scale and explicit ground anchors. `provenance.json` records sources and prompts, while `QA.md` links the validation and navigation reports. Source images and the compositor are retained under `art/maps/stage-1-1/`.

The current Stage 1-1 is free-roaming: the road is not a collider. `layout.json` supplies the world bounds and Arojinle; `environment.json` supplies solid ground radii for scenery. The generated up/back and down/front walk set is in `sprites/main-hero/directions/`, with a two-view preview and a standalone download at `sprites/main-hero-directions.zip`. Each view has eight walking frames and a neutral standing pose. Directional running uses faster walking playback. Original side-view assets and source/QA records are retained.
